# Gemini CLI

## Key Takeaways

- Gemini CLI can be used through three common paths: Google sign-in, Gemini API key, and Vertex AI.
- Google sign-in is free for eligible accounts but may be blocked by regional availability or account eligibility.
- API key access is often the most practical option for individual developers when Google sign-in is unavailable.
- Vertex AI requires Google Cloud project configuration, including project and location settings.

## Notes

- The source is primarily a practical setup guide for using Gemini CLI in different authentication modes.
- It emphasizes that Google account eligibility and API access are separate backend capabilities.
- It also includes operational steps for configuring environment variables and verifying setup.
