# Vertex AI for Gemini CLI

## Definition

Vertex AI is a Google Cloud-based deployment path for Gemini CLI that requires project-level configuration instead of a simple personal API key workflow.

## How It Works

- The user must configure Google Cloud project and location settings.
- The environment must be aligned with the target Google Cloud project.
- This path is useful when working within an existing GCP environment or enterprise setup.

## Why It Matters

- It supports production-oriented or organization-managed workflows.
- It differs from the free or personal API-key flow in both configuration and governance.
