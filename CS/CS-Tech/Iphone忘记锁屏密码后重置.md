## Iphone忘记锁屏密码后重置

重置 iPhone（会清除数据） 的常用、安全且可操作的方法按步骤列清楚（含不同机型对应的按键），并把常见问题和应对办法也写上。请按你手机型号和目前可用的设备（Windows/Mac/是否能上网）去操作。

> 重要提醒
> 
> 重置会 清除手机上所有数据。如果你有 iCloud／iTunes 备份，重置后可从备份恢复。
> 
> 重置后若启用了 查找我的 iPhone（Activation Lock），需要原 Apple ID 和密码才能激活设备；若忘记 Apple ID/密码，可去
> 
> iforgot.apple.com
> 
> 找回或联系 Apple 支持并准备购买凭证证明所有权。

### 方法一 — 使用 iCloud（查找我的 iPhone）远程抹掉（需要 iPhone 已开启「查找我的 iPhone」并联网）

在电脑或另一台手机上访问：iCloud.com，并用你 Apple ID 登录。

选择 “查找 iPhone” → 在顶部选中你的设备 → 点击 “抹掉 iPhone”（Erase iPhone）。

按提示完成远程擦除。擦除后设备会回到出厂设置，之后按步骤激活。

> 优点：无需数据线，不用连接电脑。
> 
> 缺点：设备必须联网且开启“查找我的 iPhone”。

### 方法二 — 用 电脑（Finder 或 iTunes） 通过恢复模式恢复 iPhone（适用于无法使用 iCloud 或想通过电脑重装系统）

#### 先准备

一台有 iTunes（Windows 或 macOS Mojave 及更早）或 Finder（macOS Catalina 及以后）的电脑。

原装或数据线，确保连接稳定。

解锁（若能）并在 iPhone 上选择“信任此电脑”（如果以前没信任，会提示）。若手机被锁且不能操作，进入恢复模式即可。

#### 进入恢复模式的按键（不同机型不同）

（以 iPhone 13 / iPhone 8 及更新机型为例）

先把 iPhone 连接到电脑，然后打开 iTunes/Finder。

快速按 音量加（Volume Up），再快速按 音量减（Volume Down），然后按住 侧边键（Side），直到出现恢复模式屏幕（显示连接电脑的图标或电脑/线的图示）。

iTunes/Finder 会弹出提示：“有一台 iPhone 处于恢复模式，需要更新或恢复”。选择 “恢复（Restore）”，它会下载最新系统并重装，完成后手机会被清空并重启到设置向导。

iPhone 7 / 7 Plus

同样连接电脑。按住 侧边键 + 音量减键，保持直到出现恢复模式屏幕。

iPhone 6s 及更早（带 Home 键）

连接电脑后按住 Home 键 + 侧边（或顶部）键，保持直到出现恢复模式屏幕。

> 如果 iTunes/Finder 提示需要下载系统但下载失败，或恢复失败，尝试换 USB 线/换港口/换另一台电脑再试。

### 快速流程小抄（给你一步到位的操作顺序）

如果 iPhone 联网且“查找我的 iPhone”已开 → 用 iCloud.com → 查找 iPhone → 抹掉 iPhone（最简单）。

否则用 电脑 + iTunes/Finder → 将 iPhone 进入 恢复模式 → 选择 恢复（Restore）。

如果恢复模式 fail → 进入 DFU 模式 再恢复。

恢复完成后按提示激活，如果遇到 Activation Lock，需原 Apple ID/密码或联系 Apple。
